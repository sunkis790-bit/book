# book — 자산·카드 장부 (암호화 배포본)

Google 드라이브의 `book.xlsx`를 브라우저에서 읽고 고쳐 저장하는 가계부입니다.
이 저장소는 **잠금 화면**과 **암호화된 앱 묶음**만 담고 있습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 잠금 화면. 비밀번호를 넣으면 앱을 메모리에서 열어 실행합니다. |
| `app.enc.json` | 암호화된 앱 묶음(화면 HTML, CSS, JS, 설정값) |
| `manifest.webmanifest`, `icons/` | 홈 화면 아이콘(PWA) |
| `sw.js` | 잠금 화면·암호화 파일만 캐시하는 서비스 워커(네트워크 우선) |
| `vendor/xlsx.full.min.js` | SheetJS (제3자 라이브러리) |

## 잠금 방식

- 암호화: PBKDF2-SHA256(210,000회, 16바이트 salt)로 키를 만들고 AES-256-GCM(12바이트 IV)으로 암호화합니다.
- 앱 화면·코드·OAuth Client ID·Drive 파일 ID는 모두 `app.enc.json` 안에만 있고, 저장소에 평문으로 남지 않습니다.
- 잠금 해제는 브라우저의 `crypto.subtle`로 그 자리에서 복호화하며, 비밀번호와 복호화된 내용은
  메모리에만 있고 `localStorage` 등에 저장하지 않습니다. 새로고침하면 다시 잠깁니다.
- 비밀번호는 이 저장소 어디에도 적혀 있지 않습니다. 잊으면 열 수 없으니 따로 보관하세요.
